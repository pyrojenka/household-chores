# Household Chores Manager

A tool for managing shared household chores, built with Django.

Used by one family (2 adults, 2 children) to assign chores, track completion,
and reward kids with points they can redeem for rewards.

See [`_docs/plan.md`](_docs/plan.md) for the full specification.

## Tech Stack

- Python / Django
- [uv](https://github.com/astral-sh/uv) for dependency management

## Getting Started

```bash
uv run python manage.py runserver
```
